# Apresentação do repositório no GitHub

[Voltar ao início](../README.md)

O README e as imagens em `docs/assets/` são versionados. A descrição lateral,
os tópicos e a imagem de compartilhamento são configurações do próprio GitHub;
precisam ser preenchidos no painel do repositório.

## About

Na página de [Portal 138](https://github.com/lassozx/portal-138), clique na
engrenagem ao lado de **About** e preencha:

**Descrição sugerida:**

```text
Portal de notícias da comunidade escolar SESI 138, com React, Node.js e PostgreSQL. Desenvolvido por Lasso, estudante do SENAI.
```

**Website:**

```text
https://portal-138-0vv9.onrender.com/
```

**Topics sugeridos** — adicione cada um como um tópico separado:

```text
react
javascript
nodejs
express
postgresql
prisma
tailwindcss
vite
news-portal
school-project
```

Salve em **Save changes**. Os tópicos descrevem as tecnologias e a finalidade
do projeto, ajudando quem visita seu perfil a entender o repositório.

## Imagem de compartilhamento

A imagem [social-preview.png](assets/social-preview.png) tem **1280 × 640 pixels**
e menos de 1 MB. Ela está pronta para aparecer quando o link do repositório for
compartilhado.

1. Depois de baixar a branch ou atualizar a `main`, localize
   `docs/assets/social-preview.png` no seu computador.
2. Abra [Settings do repositório](https://github.com/lassozx/portal-138/settings).
3. Na seção **Social preview**, clique em **Edit → Upload an image**.
4. Selecione `social-preview.png` e confirme a alteração.

Esse upload é uma configuração do repositório. O arquivo continuar no Git não
ativa automaticamente a imagem de compartilhamento.

## Atualizar as prévias da interface

- `portal-138-banner.svg`: banner do README.
- `portal-home.jpg`: captura da página inicial.
- `portal-admin.jpg`: captura do painel de notícias.
- `portal-mobile.jpg`: captura da página inicial no celular.
- `social-preview.png`: cartão de compartilhamento do repositório.

As capturas atuais usam a interface da versão `ae02ebb`, com dados fictícios
em uma prévia local. Não foram usadas contas, tokens ou notícias de produção.
O README identifica esse conteúdo como demonstração. Ao trocar as capturas,
mantenha essa indicação coerente com a origem das novas imagens.

Antes de versionar novas imagens, confira que elas não mostram senhas, chaves,
tokens, campos revelados de configuração ou informações pessoais de usuários.
